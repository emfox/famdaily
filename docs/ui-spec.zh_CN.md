## 0. 全局约定

### 0.1 导航骨架

```
┌─────────────────────────────┐
│ 状态栏                       │
├─────────────────────────────┤
│ 页面标题            [操作]   │  ← 顶栏，高度 44
├─────────────────────────────┤
│                             │
│         页面内容             │  ← 可滚动
│                             │
├─────────────────────────────┤
│  ◉ 今日    ▤ 历史    ⚙ 设置  │  ← 底部 Tab，仅一级页有
└─────────────────────────────┘
```

- 一级页只有 3 个：**今日 / 历史 / 设置**
- 二级页从右侧滑入，顶栏左侧为「‹ 返回」，**没有底部 Tab**
- 模态（选择器、确认、补卡弹层）从底部升起，背景变暗但可见

### 0.2 五种打卡状态的视觉规则

**这张表是全 App 最重要的约定，所有页面共用。**

| 状态 | 右侧控件 | 标题文字 | 行背景 | 附加标记 |
|---|---|---|---|---|
| 待做（未到时间） | 空心圆 ○ | 正常色 | 白 | 显示时间 |
| 待做（已过时间） | 空心圆 ○ | 正常色 | 淡红 | "迟 N 分钟"字样（红） |
| 已完成（准时） | 实心绿圆 ✓ | 灰色 + 删除线 | 白（淡绿边） | "准时" |
| 已完成（补卡） | 空心绿圆 ✓ | 灰色 + 删除线 | 白（淡绿边） | "补"角标（琥珀色） |
| 没做 | 灰色小叉 ✕ | 灰色 + 删除线 | 米白，整体淡化 | "没做"（灰） |

> 记忆口诀：**实心=准时，空心=补，叉=没做，空心待做=还来得及。**

### 0.3 字号与尺寸基线

| 用途 | 字号 | 说明 |
|---|---|---|
| 页面标题 | 17pt 600 | |
| 打卡项名称 | 14pt 550 | |
| 元信息（成员/时间） | 11pt 400 | 次要灰 |
| 勾选控件 | 26×26 | 触控区扩大到 44×44 |
| 列表行高 | 56pt | 单手易点 |

老人相关页面（网页端成员页）字号放大到 **1.6 倍**，按钮最小高度 **48pt**。

## 1. 今日清单（首页）

**入口**：App 启动直落此页 · 点系统通知直达并高亮对应项

```
┌─────────────────────────────┐
│ 08:20                        │
│ 今天                    [⋯]  │  ← ⋯ = 新建打卡项
│ ┌─────────┬─────────┐       │
│ │ 时间轴  │  成员   │       │  ← 分段控件，默认时间轴，记住选择
│ └─────────┴─────────┘       │
│ 今天已完成            3 / 9  │
│ ▓▓▓▓▓░░░░░░░░░░░░░░░        │  ← 4pt 细进度条
├─────────────────────────────┤
│ 今天漏了 ────────────────    │  ← 红字分组标题
│ ┌─────────────────────────┐ │
│ │[爷] 降压药              ○│ │  ← 淡红底
│ │     爷爷 · 7:30 · 迟50分 │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │[宝] 早读 20 分钟         ○│ │
│ │     小宝 · 7:00 · 迟80分 │ │
│ └─────────────────────────┘ │
│                             │
│ 已完成 ──────────────────    │
│ ┌─────────────────────────┐ │
│ │[我] ~~喝水 300ml~~      ✓│ │  ← 实心绿
│ │     我 · 8:00 · 准时 📷1 │ │
│ └─────────────────────────┘ │
│      [＋备注] [＋照片]       │  ← 点勾后才浮出，3 秒自动收起
│ ┌─────────────────────────┐ │
│ │[妈] ~~维生素~~          ✓│ │
│ │     妈妈 · 8:00 · 代勾   │ │  ← 代勾的显示"代勾"
│ └─────────────────────────┘ │
│                             │
│ 接下来 ──────────────────    │
│ ┌─────────────────────────┐ │
│ │[爷] 降压药            (1/3)│ │  ← 一日多次显示进度
│ │     爷爷 · 12:30        │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│  ◉ 今日   ▤ 历史   ⚙ 设置   │
└─────────────────────────────┘
```

**交互**

| 动作 | 结果 |
|---|---|
| 点勾选圈 | 立即变绿、标题划线、行变淡、进度条 +1，下方浮出「＋备注 ＋照片」，3 秒后收起 |
| 点已完成的勾 | 撤销（回到待做） |
| 点行内文字区 | 进入打卡项详情 |
| 点超时那条的勾 | 弹出「两个出口」选择（见 1.2），因为已经过点 |
| 下拉 | 强制同步（P3 才有意义，P1 只刷新本地） |
| ⋯ | 菜单：新建打卡项 / 管理打卡项 |

**排序规则（时间轴视图）**

1. 超时未完成 → 置顶，按超时长度倒序（最久最上）
2. 已完成 → 居中，按完成时间正序
3. 未到时间 → 在后，按时间正序

> 已完成项**不折叠**。它存在的意义是"我今天确实做了这些"，是给用户的确定感，折叠掉就看不见了。

### 1.1 成员视图（同一页，切换排法）

```
│ ┌─────────────────────────┐ │
│ │[爷] 爷爷           1 / 3│ │  ← 成员卡片
│ │─────────────────────────│ │
│ │ 7:00  ~~晨起量血压~~   ✓│ │
│ │ 7:30  降压药（红）      ○│ │
│ │12:30  降压药 2/3        ○│ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │[宝] 小宝           0 / 2│ │
│ │─────────────────────────│ │
│ │ 7:00  早读 20 分钟（红）○│ │
│ │20:00  跳绳 200 个       ○│ │
│ └─────────────────────────┘ │
```

- 成员卡按成员排序排列
- 点成员头像 → 成员详情
- 每张卡内项目按时间正序，不分组

### 1.2 漏卡的两个出口（模态）

超时的项被点击时，**不直接打卡**，而是弹出选择——因为已经过了时间，系统无法判断是"刚做"还是"漏了"。

```
┌─────────────────────────────┐
│        （背景变暗）           │
│                             │
│ ┌─────────────────────────┐ │ ← 从底部升起
│ │         ───             │ │
│ │ 小宝 · 早读 20 分钟      │ │
│ │ 7:00 · 这件事最后怎么样？│ │
│ │ ┌─────────────────────┐ │ │
│ │ │ ✓ 做了，只是当时忘了记│ │ │ ← 绿底
│ │ │   记为补卡·算完成不算准时│ │
│ │ └─────────────────────┘ │ │
│ │ ┌─────────────────────┐ │ │
│ │ │ ✕ 没做              │ │ │ ← 淡红底
│ │ │   老实记一笔，这条就结案│ │ │
│ │ └─────────────────────┘ │ │
│ │      算了，不改          │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

> **只有两个选项 + 一个取消。** 不提供"先不管"按钮——什么都不点就等于没做，明天 0 点自动结案。

### 1.3 空状态

```
│                             │
│        还没有打卡项          │
│   给家人加一件每天要做的小事  │
│                             │
│      [ 从模板开始 ]          │
│                             │
```

## 2. 新建打卡项

**入口**：今日清单右上角「⋯」→ 新建打卡项
**形态**：三步式二级页，顶栏右侧「保存」在必填项齐了之后才变绿

```
步骤1 选模板  →  步骤2 填信息  →  步骤3 设时间  →  保存
```

### 2.2 步骤 2：填信息

```
┌─────────────────────────────┐
│ ‹模板   基本信息       保存  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 叫它        降压药     ✎│ │ ← 文本输入
│ │─────────────────────────│ │
│ │ 谁做   [爷爷][小宝][我][妈]│ │ ← 单选的胶囊按钮
│ │─────────────────────────│ │
│ │ 图标  [💊][💧][🩺][🌿][更多]│ │
│ │─────────────────────────│ │
│ │ 说一句                   │ │
│ │ 白色药片 2 粒，饭后半小时 │ │ ← 多行，可不填
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- 「说一句」是**事前说明**（给打卡的人看），不是事后备注
- 除「叫它」「谁做」外均非必填，**不做强校验**

### 2.3 步骤 3：设时间

**收起态（默认，覆盖 90% 场景）**

```
┌─────────────────────────────┐
│ ‹信息   什么时候做      保存 │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │[每天一次][一天几次][自定]│ │ ← 三段 Tab，默认「一天几次」
│ │─────────────────────────│ │
│ │ 跟三餐走                 │ │
│ │  早饭            7:30   │ │
│ │               〔饭后30分〕│ │
│ │  午饭           12:30   │ │
│ │               〔饭后30分〕│ │
│ │  晚饭           18:30   │ │
│ │               〔饭后30分〕│ │
│ │─────────────────────────│ │
│ │ 用餐时间可以自己改    7:00/12:00/18:00 ▾ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 更多规则  每周几、每隔几小时 ▾│ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 预览：爷爷 · 降压药          │ ← 置底固定，自然语言复述
│ 每天 7:30 / 12:30 / 18:30   │
└─────────────────────────────┘
```

**三个 Tab 的实际区别**

| Tab | 内部状态 | 用户看到 |
|---|---|---|
| 每天一次 | 单个 time picker | 一个时间轮 |
| 一天几次 | 方式选「跟三餐」或「N 次」，N∈[1,6] | 跟三餐→三餐行；N 次→N 个时间行 |
| 自己定时刻 | 时间点数组，可增删 | 列表 + 「＋ 添加时间」 |

> 底层是同一个结构：`repeatRule + timePoints + course`。「跟三餐走」只是**预填了 3 个 timePoints** 的快捷方式，
> 填完照样能手动改其中任意一个。这一点实现时必须真的落到 timePoints 上，不能做成两套逻辑。

**展开态：更多规则**

```
│ ┌─────────────────────────┐ │
│ │ 更多规则              ▴ │ │ ← 展开
│ │─────────────────────────│ │
│ │ 哪天做（默认每天）        │ │
│ │ 一 二 三 四 五 六 日      │ │
│ │ ✓  ✓  ✓  ✓  ✓  ✓  ✓     │ │ ← 圆点可点
│ │ [工作日][周末][每天]      │ │ ← 快捷
│ │─────────────────────────│ │
│ │ 或者按间隔                │ │
│ │ 每 [2] 小时，从 [9:00] 到 [21:00] │ │
│ │ （不填就不用这个规则）     │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 高级   隔周、每月几号、按完成推下次 ▸│ │
│ └─────────────────────────┘ │
```

**高级（第三层，再展开）**

| 规则 | 参数 | 语义 |
|---|---|---|
| 隔周 | 起始周 | 每两周一次 |
| 每月固定日 | 日号数组 [1,15] | 每月这些日子 |
| 按完成推下次 | 间隔小时数 | 上次**完成**后 N 小时再提醒，不看钟点 |
| 多时间段 | 若干组「起-止」 | 如上午 9–11、下午 15–17 |

### 2.4 疗程（并入步骤 3 底部，或独立小块）

```
│ 做多久                       │
│  [一直做] [做一段时间]        │
│  连着做 [7] 天  到 10/30 结束 │
│  或 指定起止日期          ›  │
```

- 默认「一直做」
- 到期后：自动归档、停止提醒、记录完整保留、项目列表出「再来一轮」

## 4. 打卡项详情

**入口**：点今日清单里某项的文字区

```
┌─────────────────────────────┐
```

**三条语义必须严格区分（实现时不要合并）**

| 操作 | 提醒 | 今日清单 | 记录 | 可恢复 |
|---|---|---|---|---|
| 暂停 | 停 | 不出现 | 保留 | 随时恢复 |
| 归档 | 停 | 不出现 | 保留 | 需「再来一轮」 |
| 删除 | 停 | 不出现 | **保留**（脱离项目归属） | 不可 |

**改规则不影响历史**：修改时间规则后，已发生的记录按当时规则计算，不会变成迟到。

## 8. 实现优先级

| 阶段 | 页面 | 说明 |
|---|---|---|
| **P1** | 1 今日清单（双视图）· 2 新建项目（三步）· 4 项目详情 · 5 成员（列表/新增/详情）· 6 设置 · 6.1 数据管理 · 6.2 导出 | 单机可用闭环 |
